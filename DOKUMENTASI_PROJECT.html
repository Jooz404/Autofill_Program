Dokumentasi Pertamina S&D Autofill Assistant

Sistem otomatisasi penginputan data Penyaluran RSD Pertamina Patra Niaga berbasis Chrome & Edge Extension Manifest V3 dengan arsitektur OOP dan State Machine.

Manifest V3 OOP Architecture S&D One Portal Compatible

1. Gambaran Umum Proyek

Pertamina S&D Autofill Assistant dirancang untuk mempercepat dan menghilangkan potensi kesalahan manusia (*human error*) dalam proses penginputan data transaksi Penyaluran Mobil Tangki di portal web S&D One (Supply & Distribution) (https://sndone.patraniaga.com/).

Parsing Excel Masal

Membaca data ratusan transaksi secara instan dari berkas Excel (.xlsx) termasuk LO dan Segel ganda.

Dual-Tank In-Line Blending

Dukungan otomatisasi pengisian tangki ganda untuk produk campuran seperti Biosolar B50 (Solar + FAME) & Dexlite.

Select2 Helper Cerdas

Pencarian opsi dropdown jQuery Select2 berbasis fuzzy matching (exact, serial TK-xx, keyword, fallback).

Monitoring Real-Time

Terminal log interaktif dan progress bar pengerjaan transaksi secara langsung dari popup ekstensi.

2. Arsitektur & State Machine Flow

Sistem menggunakan alur state linier yang menyimpan progres di chrome.storage.local sehingga aman dari page reload atau navigasi antar-halaman web.

[ File Excel .xlsx ] ──> [ ExcelParser ] ──> [ chrome.storage.local ]
                                                    │
                                                    ▼
                                    [ AutofillEngine (Orchestrator) ]
                                                    │
     ┌──────────────────────┬───────────────────────┼───────────────────────┐
     ▼                      ▼                       ▼                       ▼
[ ListPageHandler ]  [ PenyaluranAddHandler ] [ ProcessBridgeHandler ] [ Stage Handlers ]
 - Cek draft/complete  - Register penyaluran   - Routing sub-aktivitas  - GateInPageHandler
 - Skip if completed   - Isi Moda & SPBU                                - PengisianPageHandler
                                                                        - GateOutPageHandler

3. Struktur File Proyek

Nama File Tipe Fungsi & Peranan Utama
manifest.json JSON Manifest V3 Konfigurasi ekstensi, izin storage, host permissions sndone.patraniaga.com.
popup.html HTML Interface Antarmuka Control Panel (Upload, Gauge, Buttons, Logs Terminal) & Tab Setting Tanki.
popup.css Vanilla CSS Desain UI modern Pertamina corporate theme (Dark Mode & accent colors).
popup.js JavaScript (OOP) Controller popup: LoggerUI, DateFormatter, TankConfigManager, ExcelParser, PopupAppManager.
content.js JavaScript (OOP) Engine otomasi di portal: Select2Helper, DOMUtils, BasePageHandler, 6 Page Handlers, AutofillEngine.
xlsx.full.min.js JS Library Library SheetJS lokal untuk membaca binary file Excel secara offline tanpa CDN.

4. Penjelasan Modul & Kelas OOP (content.js & popup.js)

4.1 Engine Automation (content.js)

  • Select2Helper: Menangani pembukaan dropdown Select2 dan pemilihan opsi secara presisi. Mengenali container select2-container Select2 V4 dan mencocokkan format nomor tangki dinamis (seperti 8 atau 15 yang secara otomatis dicocokkan ke T008 - TK-08 dan T015 - TK-15).
  • DOMUtils: Pembantu manipulasi DOM seperti ekstraksi NIP driver dari Nama [ID], simulasi MouseEvent asli (mousedown, mouseup, click), dan verifikasi status Completed.
  • ListPageHandler: Mengelola daftar penyaluran di halaman utama.
    • Menggunakan perbandingan Nopol presisi (DOMUtils.isRowMatchNopol) yang mengabaikan spasi/format (misal DB 8015 RK match ke DB8015RK).
    • Hanya memilih baris yang persis cocok dengan plat nomor target Excel.
    • Menghapus total fallback acak yang sebelumnya bisa mengklik baris truk lain. Jika Nopol target tidak ada di tabel, bot langsung menekan tombol + Add New (#btn-add-penyaluran) untuk membuat pendaftaran baru.
    • Melompati (skip) baris Excel secara otomatis jika transaksi untuk Nopol tersebut sudah berstatus Complete.
  • PenyaluranAddPageHandler: Pengisian otomatis form awal penyaluran (Moda: TRUCK, Tujuan: SPBU, Nomor Polisi).
  • ProcessBridgePageHandler: Jembatan navigasi stepper yang secara cerdas memilih dan mengklik tautan sub-aktivitas (Gate In, Pengisian, atau Gate Out).
  • GateInPageHandler: Pengisian MT Gate In (AMT Driver & Waktu Gate In). Mampu menangani mode View ke mode Edit (#btn-editing), simpan draf (#btn-draft), dan submit final (#btn-completed / #btn-completedEdit).
  • PengisianPageHandler: Pengisian multi-LO via dialog modal. Mengatur dual-tank In-Line Blending, nomor tangki, Bay Number, No Meter, Volume Liter, perhitungan string kompartemen (contoh: 1.2), serta validasi Meter Awal/Akhir otomatis.
  • GateOutPageHandler: Pengisian nomor segel ganda dan Waktu Gate Out, simpan draf, dan submit transaksi akhir.

6. Pengaturan Tangki & In-Line Blending

Di tab Setting Tanki pada popup ekstensi, pengguna dapat menyesuaikan nomor tangki aktif harian:

In-Line Blending Dual Tank

Untuk produk BIOSOLAR B50 dan DEXLITE, sistem akan otomatis mencentang opsi In-Line Blending pada modal pengisian dan memilih Tanki 1 (Solar/Main) dan Tanki 2 (FAME/Secondary) secara terpisah!

7. Panduan Instalasi Browser

  1. Buka browser Microsoft Edge (edge://extensions/) atau Google Chrome (chrome://extensions/).
  2. Aktifkan Developer Mode (Mode Pengembang) di bagian pojok antarmuka browser.
  3. Klik tombol Load unpacked (Muat ekstensi yang tidak dikemas).
  4. Pilih folder proyek: C:\Users\Josua\Downloads\Magang_Pertamina\Project Autofill RSD.
  5. Ekstensi Pertamina S&D Autofill Assistant siap digunakan!

8. Cara Penggunaan Langkah demi Langkah

  1. Buka dan login ke portal S&D One Pertamina (https://sndone.patraniaga.com/).
  2. Klik ikon ekstensi S&D Autofill di toolbar browser.
  3. Buka tab Setting Tanki untuk menyesuaikan nomor tangki hari ini.
  4. Buka tab Control Panel, upload file snd1.xlsx via Drag & Drop.
  5. Klik tombol Mulai Autofill. Pantau pergerakan bot pada log terminal popup.

9. Troubleshooting & Penanganan Kendala

Peringatan Tab Aktif

Jika muncul log "Koneksi ke tab aktif: Harap pastikan tab aktif berada di portal S&D...", pastikan tab browser yang sedang terbuka dan aktif di layar komputer Anda adalah halaman portal sndone.patraniaga.com.

Reset Antrean Transaksi

Jika ingin menghentikan pengerjaan atau meng-upload file Excel baru, tekan tombol Hentikan kemudian klik Reset Data untuk membersihkan storage ekstensi.

10. Panduan Backup Git & GitHub (Version Control)

Untuk menghindari penggunaan backup berkas ZIP yang memakan tempat, gunakan **Git** dan **GitHub** untuk menyimpan setiap titik perkembangan fitur yang berhasil dan kembali ke versi lama jika terjadi kesalahan.

1. Inisialisasi Project (Awal)

git init
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git

2. Backup Rutin Fitur Baru

git add .
git commit -m "Deskripsi fitur"
git push -u origin main

3. Batal Edit / Restorasi Versi

# Batal edit sebelum commit:
git restore .

# Reset ke commit lama:
git reset --hard <COMMIT_HASH>
Panduan Lengkap Git

Panduan langkah demi langkah yang lebih detil telah tersedia di berkas PANDUAN_GIT_GITHUB.md di folder proyek.
